# Madrid, Well Chosen

A static guide to distinctive Madrid bars, restaurants, rooftop dining and cafés, with a dark plum and purple theme, rose accents and softly lit photo galleries.

The guide covers 27 venues, each with at least 15 photos. Baton Rouge is explicitly marked as an archival entry because current listings report it permanently closed. Beata Pasta refers to Bilbao; Ôven refers to Gran Vía 6.

Open `index.html` for bars and `restaurants.html` for restaurants and cafés. Keep the HTML files and `assets/` directory together. No build step, framework or API key is needed.

Each venue has menus, booking guidance, December considerations and an inline photo gallery. The 411 verified photos and their thumbnails are bundled under `assets/photos/`, so galleries do not depend on third-party image hosts. Original source credits remain linked. Photos may show previous décor or menus. If an image fails, the gallery skips it for that page visit and hides its thumbnail; empty categories offer a clear fallback.

`assets/photos/manifest.json` records each photo’s source URL, credit, dimensions and SHA-256 checksum. Photos were downloaded, decoded and visually reviewed on 26 October 2026. Copyright remains with the respective photographers and publishers.

Rooftop dinner budgets are editorial estimates based on linked menus, not confirmed festive-package prices. Venue information was expanded on 26 October 2026; existing ranking references were researched on 25 October 2026. Recheck official sources before booking.

For GitHub Pages, publish the root of the `main` branch. `.nojekyll` serves the HTML directly. The site contains no visitor analytics or injected advertising.
